Validador de RFC y CURP

Escribe una clave y ve qué significa cada parte y si su dígito verificador cuadra. Detecta errores de captura antes de timbrar una factura o dar de alta a alguien. Nada sale de tu navegador.

    Ejemplos:

    Revisa una lista completa

    Pega una columna de Excel con RFC, CURP o ambos, uno por renglón. Se detecta cuál es cuál.

    Úsalo en tu código

    Paquete de npm sin dependencias, con tipos de TypeScript.

    npm install @gustavoquintero/rfc-curp

import { validarRfc, validarCurp } from '@gustavoquintero/rfc-curp';

validarRfc('GODE561231GR8');
// { valido: true, tipo: 'fisica', fecha: '1956-12-31', homoclave: 'GR8', errores: [] }

validarCurp('BOXW310820HNERXN08').errores;
// ['El dígito verificador debería ser "9" y es "8". Probablemente hay un error de captura.']
